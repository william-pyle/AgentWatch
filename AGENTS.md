# Agent Watch for Windows

This is the independent Windows application. Alpha workbench records and the preserved original village remain at C:/Projects/AlphaWorkspace/projects/agent-watch. Do not change those originals or restart any existing watchers or chats.

Application code is in src/. Themes are declarative JSON and image assets under themes/. Robot Datacenter is the bundled default; Mooseville is an optional download with byte-identical approved artwork and map. Preserve their provenance. Never commit live observations, chat history, local settings, credentials or signing keys.

Use npm test, npm run themes:check and npm run test:desktop after runtime changes. Build the Windows installer with npm run build. Commit package-lock.json. Theme catalog hashes are generated by npm run themes:build. The tag workflow publishes Windows releases; main updates publish theme changes immediately through raw GitHub content.

Keep theme packs data-only, validate references and paths, download to staging and activate only complete verified packs. Never overwrite personal themes or user activity overrides during updates. Keep public guides in HTML and structured sources in JSON. Preserve IDs.

Every future app, release or theme update must also update the Alpha workspace in
the same task. Read C:/Projects/AlphaWorkspace/projects/agent-watch/AGENTS.md and
preserve the owner's approved format: Overview, Guide, Releases and Artwork, in
that order, with the existing layout, styling and artwork galleries by theme.
Keep the guide, current release links/version, verification records, screenshots
and affected theme galleries synchronized. Extend the existing templates; do not
redesign the format or restore retired-version documentation unless requested.
Rebuild with node C:/Projects/AlphaWorkspace/projects/agent-watch/build.mjs and
complete the workspace checks before reporting the update finished. If that
workspace is unavailable, explicitly report the documentation update as pending.
